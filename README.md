# Your Ani List

A anime backlog solver that helps you clear backlogs with just one click! ^-^

## 🚀 Features
- No clutter UI
- Responsive user interface
- Only focuses on existing list
- No discovery to avoid "doom-discovery"

## 🛠️ Tech Stack
- **Frontend:** Vanllia HTML,CSS,JS
- **Backend:** Static Github Pages

## How to run
- Just open the link 
([text](https://doomedzero.github.io/your-ani-list/))
